# Проект управления совместными расходами

Backend-приложение для управления совместными расходами: создания групп, добавления участников, учёта трат и распределения расходов между пользователями.

## Возможности

- **Аутентификация:** регистрация и вход по email и паролю, авторизация через Google OAuth.
- **Управление сессиями:** JWT access- и refresh-токены, ротация токенов и обнаружение повторного использования.
- **Подтверждение email:** верификация адреса электронной почты.
- **Группы:** создание групп, приглашение участников и управление членством.
- **Расходы:** создание расходов и распределение сумм между участниками.
- **Мультивалютность:** конвертация валют с использованием курсов Frankfurter и кеширования в Redis.
- **Уведомления:** обработка и отправка событий через механизм Outbox.
- **Мониторинг:** инструментация приложения с помощью OpenTelemetry.

## Технологии

- **NestJS** и **TypeScript**
- **Prisma** — работа с данными
- **Zod** — валидация
- **Redis** — кеширование
- **OpenTelemetry** — мониторинг и трассировка
